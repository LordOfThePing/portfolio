# portfolio

## Workflow override

En este proyecto, pusheá los commits de código vos mismo después de
commitearlos. Esto sobreescribe el default global (`~/.claude/CLAUDE.md`) que
dice que el push lo hace el usuario.

- Trabajá en `main`, commits aislados por cambio.
- Al terminar un cambio: commit → push.
- Sigue vigente: no `git push --force`, no abrir PRs sin pedido explícito.
